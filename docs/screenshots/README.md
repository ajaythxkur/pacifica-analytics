# Screenshots — capture checklist

Drop your screenshots in this folder using the filenames below. The main repo
README references several of these so the GitHub page renders nicely.

Recommended capture environment:
- Browser window: 1440 × 900 (or wider, for retina captures)
- Hard refresh first so animations play through cleanly
- Dark theme is the default but feel free to capture both

## Required (referenced from the root README)

| File | What to capture |
|---|---|
| `01-home.png` | The home page hero with the search bar, stats tiles, and the "Top Traders" table visible |
| `02-leaderboard.png` | The full leaderboard with the period filters (1D / 7D / 30D / ALL) and a few rows hovered |
| `03-trader-profile.png` | A trader profile with both PnL by Period and Volume by Period charts visible, plus a few StatCards |
| `04-trader-tabs.png` | The Positions / Open Orders / Trade History / Funding tabs row, on the Trade History tab so PnL + LIQ badges are visible |
| `05-compare.png` | The /compare page with 2–3 traders loaded and the bar charts rendering |
| `06-alerts.png` | The /alerts page with the Telegram bot CTA banner visible at the top and a few whale alerts in the feed |
| `07-sentiment.png` | The /sentiment page showing the BTC stats card + trending tokens + tweet feed |
| `08-groups.png` | The /groups page with at least one custom group created |
| `09-flex-card.png` | A flex card modal open on top of a trader profile |
| `10-telegram-alert.png` | A real Telegram alert message in the bot chat showing all 4 inline buttons |

## Nice-to-have

- `11-light-theme.png` — same as the home page but with the light theme toggled
- `12-mobile-home.png` — narrow viewport / mobile capture
- `13-bot-commands.png` — Telegram chat showing /start, /subscribe, /status output

## Tips

- For the Telegram alert capture, use a wallet like the top-1 whale and lower
  your `/setmin` to 1000 to trigger an alert quickly.
- For the Compare capture, use 3 traders so all 6 comparison charts have
  enough data to look interesting.
- The trader profile is best captured for a top-10 wallet so the numbers
  look impressive (e.g. all-time PnL > $1M).
